## 개발 대상

실제 크레인을 사용하지 않고 상위 자동화 시스템의 장비 연동을 검증할 수 있도록 다음 프로그램을 개발했습니다.

| 프로그램 | 용도 |
|---|---|
| ECS 에뮬레이터 | 야드 크레인 작업 명령과 장비 상태 재현 |
| STS 에뮬레이터 | 안벽 크레인의 선박 하역 작업 재현 |
| RFID 에뮬레이터 | 차량·컨테이너 식별 데이터 입력 |
| 차단기 제어 도구 | 외부 설비 상태와 제어 명령 검증 |
| 센서 보정 도구 | 장비 좌표와 센서값 보정 시험 |

<!--more-->

## 공통 구조

에뮬레이터 본체는 다음 영역으로 분리했습니다.

1. TCP 연결, 송수신 큐와 재접속을 담당하는 통신 계층
2. 현장별 메시지 형식 변환과 파싱을 담당하는 프로토콜 계층
3. 장비, 위치, 컨테이너와 작업 상태를 관리하는 도메인 계층
4. 선행 조건, 작업 단계와 완료 조건을 처리하는 Sequence 계층
5. 상태 모니터링과 수동 제어를 제공하는 WinForms 화면
6. 설정, 로그와 테스트 데이터를 관리하는 데이터 서비스

## ECS 에뮬레이터

야드 크레인의 주요 동작과 상태를 재현했습니다.

- Gantry·Trolley·Hoist 축 이동
- Spreader 크기와 적재 상태
- 블록·베이·열·단 위치
- 컨테이너 Pickup·Putdown
- 자동·수동 운전 모드
- 작업 수락, 시작, 진행, 완료와 거절
- 복수 크레인 연결과 개별 세션
- 장비 간 작업 영역 충돌 조건

## STS 에뮬레이터

안벽 크레인의 선박 하역 작업을 다음 단위로 구현했습니다.

- 선박, 플랫폼과 차량 위치
- Main·Portal Trolley
- Hoist와 Spreader 동작
- Single·Twin Container 작업
- 단일·이중 트롤리 작업
- 차량 도착과 작업 가능 상태 확인
- 대기 작업의 실행 후보 선정

## 검증 시나리오

- 정상 명령의 수락부터 완료 보고
- 연결 단절과 재접속
- 잘못된 명령과 작업 거절
- 실행 중 작업 중단
- 장비 위치와 컨테이너 상태 불일치
- 복수 장비 동시 연결
- 현장별 메시지 규격 차이

## 기술 스택

`C#`, `.NET Framework 4.7.2`, `WinForms`, `비동기 TCP Socket`, `Spring.NET`, `iBATIS`
