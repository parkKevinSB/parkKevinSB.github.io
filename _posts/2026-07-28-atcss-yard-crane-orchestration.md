## 시스템 역할

ATCSS는 TOS의 컨테이너 작업지시를 실제 야드 크레인 제어 시스템인 ECS가 처리할 수 있도록 변환하고 작업 완료까지 상태를 관리합니다.

<!--more-->

| 단계 | 처리 내용 |
|---|---|
| 작업 수신 | TOS 작업 생성·갱신·취소 메시지 처리 |
| 검증 | 컨테이너 위치, 야드 재고, 장비와 작업 상태 확인 |
| 작업 선정 | 실행 가능한 작업과 대상 크레인 결정 |
| 명령 전송 | ECS 장비 명령 생성 및 전송 |
| 진행 관리 | 명령 수락, 실행, 완료·중단 상태 반영 |
| 결과 반영 | DB 상태 갱신 및 TOS 결과 보고 |

## 운영 유지보수

국내 2개, 일본 1개, 중동 1개 터미널을 담당했습니다.

- 작업 생성·배차·취소와 완료 보고 오류 분석
- 야드 재고와 실제 컨테이너 위치 동기화
- ECS 연결 단절·재접속 후 작업 상태 복구
- 중복 작업지시와 중복 완료 보고 방지
- 공통 코어 변경 시 다른 사이트 영향 확인
- Oracle·MSSQL 데이터와 로그를 이용한 장애 추적

## 일본 신규 사이트

기존 ATCSS 제품을 신규 터미널 환경에 맞게 개발했습니다.

- TOS·ECS 인터페이스 분석
- 사이트별 Spring 설정과 DB 구성
- 신규 터미널 작업 규칙 구현
- ECS 에뮬레이터를 이용한 연동 시험
- 배포 및 현장 롤아웃

## ECS 에뮬레이터

ATCSS의 장비 명령을 수신하고 실제 ECS와 동일한 작업 상태를 반환하도록 구현했습니다.

- 명령 수락과 거절
- 작업 진행과 완료 보고
- 비정상 상태와 작업 중단
- 연결 단절과 재접속
- 반복 가능한 작업 시나리오
