## 대상과 목적

대상 시스템이나 기술은 무엇이며 어떤 업무를 처리하는가?

## 담당 범위

- 신규 개발, 유지보수 또는 적용 범위
- 담당한 모듈과 기능
- 공개 글에서 생략하거나 일반화할 정보

## 적용 구조

구성 요소와 처리 흐름을 객관적으로 정리합니다.

## 주요 동작

## 사용 기술

언어, 프레임워크, 통신 방식과 데이터 저장 기술을 정리합니다.

## 검증 결과

적용, 롤아웃 또는 테스트로 확인한 범위를 적습니다.
