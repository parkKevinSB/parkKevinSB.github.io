## 개발 목적

실제 야드 크레인과 안벽 크레인이 준비되지 않았거나 운영 중인 상황에서도 상위 자동화 시스템을 개발·검증할 수 있도록 장비 통신과 작업 상태를 재현했습니다.

## ECS 에뮬레이터

ECS는 야드 크레인의 실제 제어 프로그램을 대체하는 검증 대상입니다.

- 상위 시스템의 작업 명령과 제어 명령 수신
- 주행·횡행·권상 축과 스프레더 동작
- 블록, 베이, 열, 단 위치 이동
- 컨테이너 픽업·적치와 스프레더 적재 상태
- 자동·수동 운전 상태와 작업 가능 조건
- 작업 수락, 진행, 완료, 거절과 중단 보고
- 복수 크레인의 개별 통신 세션 관리
- 현장별 메시지 변환과 장비 Profile 분리

## STS 에뮬레이터

STS는 선박과 육상 사이의 컨테이너 하역 작업을 검증하기 위한 안벽 크레인 에뮬레이터입니다.

- 갠트리, 트롤리, 호이스트와 스프레더 동작 모델
- 단일·이중 트롤리 작업
- 선박, 플랫폼과 차량 사이의 컨테이너 이동
- 컨테이너 적재 순서와 작업 가능 조건
- 장비 위치, 진행 단계와 작업 완료 상태 보고
- 대기 작업에서 다음 실행 후보를 선정하는 스케줄링

## 공통 구조

| 영역 | 구현 내용 |
|---|---|
| 통신 | 비동기 TCP 연결, 송수신 큐, 메시지 분리, 재접속 |
| 메시지 | 프로토콜별 변환, 파싱, 처리기와 응답 생성 |
| 도메인 | 장비, 작업, 위치, 컨테이너와 스프레더 상태 |
| 실행 | 작업 Sequence, 선행 조건, 대기, 완료와 실패 처리 |
| 화면 | 장비 상태 모니터링, 수동 제어, 작업 조회 |
| 데이터 | 설정, 작업 기록, 장비 상태와 테스트 데이터 관리 |

## 연동 검증 도구

- RFID 입력 에뮬레이터
- 차단기 및 주변 설비 상태 제어
- 센서 좌표 보정 도구
- 외부 인터페이스 송수신 확인 도구
- 장비별 연결 상태와 메시지 로그 화면

## 검증 항목

- 정상 작업의 명령부터 완료 보고까지 전체 흐름
- 실행 중 연결 단절과 재접속
- 잘못된 명령, 작업 거절과 중단
- 장비 간 작업 영역 충돌과 물리 제약
- 복수 장비 동시 연결
- 현장별 메시지 규격 차이
