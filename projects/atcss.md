## 시스템 개요

ATCSS는 TOS와 야드 크레인 제어 시스템인 ECS 사이에서 컨테이너 작업을 실행하는 모듈입니다.

<ol class="flow-list">
  <li>TOS의 작업 생성·변경·취소 지시를 수신합니다.</li>
  <li>컨테이너 위치, 야드 재고, 장비 상태와 실행 조건을 검사합니다.</li>
  <li>실행 가능한 작업을 선택하고 크레인에 배차합니다.</li>
  <li>ECS가 처리할 수 있는 장비 명령으로 변환해 전송합니다.</li>
  <li>명령 수락, 실행, 완료와 중단 상태를 추적합니다.</li>
  <li>작업 결과와 재고 변경 내용을 DB와 TOS에 반영합니다.</li>
</ol>

## 담당 사이트

| 구분 | 담당 범위 |
|---|---|
| 국내 2개 터미널 | 운영 장애 분석, 기능 수정, 장비·작업 상태 동기화 |
| 일본 운영 터미널 | 기존 운영 시스템 유지보수 |
| 중동 터미널 | 운영 유지보수 및 현장별 연동 대응 |
| 일본 신규 터미널 | 현장 요구 분석, 사이트 개발, 연동 검증, 배포와 롤아웃 |

## 주요 유지보수

- TOS 작업 생성·갱신·취소와 완료 보고 처리
- 야드 재고와 실제 컨테이너 위치 불일치 분석
- 크레인 상태, 작업 상태와 명령 진행 단계 동기화
- 중복 명령, 통신 단절과 재접속 후 잔여 작업 처리
- 완료 보고 실패 시 재시도와 복구
- 공통 코어와 사이트별 구현의 영향 범위 확인
- Oracle·MSSQL 데이터와 운영 로그를 이용한 장애 추적

## 일본 신규 사이트

기존 ATCSS 제품을 기반으로 신규 터미널에 필요한 사이트 기능을 개발했습니다.

- 신규 TOS 메시지와 ECS 장비 프로토콜 분석
- 사이트별 Spring 설정과 데이터베이스 구성
- 작업 생성, 배차, 이동과 완료 규칙 반영
- 현장 장비 상태와 예외 조건에 맞는 처리 추가
- 연동 시험, 배포와 롤아웃 수행

## ECS 에뮬레이터 검증

실제 크레인을 상시 사용할 수 없는 개발 단계에서 ATCSS와 동일한 통신 상대 역할을 수행하는 ECS 에뮬레이터를 개발했습니다.

- ATCSS 명령 수신과 수락 응답
- 크레인 작업 진행·완료 상태 보고
- 통신 단절과 재접속
- 작업 거절·중단과 비정상 응답
- 반복 가능한 작업 시나리오 실행

에뮬레이터를 이용해 실제 장비 투입 전에 TOS부터 ATCSS, ECS까지 이어지는 작업 흐름을 검증했습니다.

<p class="scope-note">ATCSS 제품 전체를 처음부터 개발한 것은 아닙니다. 공개 경력에는 운영 유지보수, 일본 신규 사이트 기능 개발, ECS 에뮬레이터 검증과 롤아웃 범위만 기재합니다.</p>
